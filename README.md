# pocketSMM — бот челленджа + Robokassa (без сайта)

Воронка: `/start` → согласие с офертой и политикой (кнопки «Политика», «Оферта», «Продолжить») → меню → бесплатный чек-лист → описание и цена → ссылка на оплату Robokassa + кнопка «Проверить оплату» → **челлендж прямо в боте**.

## Челлендж в боте

Участники друг друга не видят — никакого общего чата.

- Сразу после оплаты: приветствие и **День 1**. Дальше по одному дню раз в `DAY_INTERVAL` (сутки), после 7-го — финальное сообщение. Прогресс хранится в базе, перезапуск бота ничего не сбивает.
- Под каждым заданием кнопка **«📝 Сдать задание»**: всё, что участник пришлёт (текст, фото, видео, голосовые, файлы), копируется всем кураторам (`ADMIN_IDS`) с пометкой «Задание дня N — имя». «✅ Готово» завершает сдачу.
- Любое другое сообщение оплатившего участника уходит кураторам как **«❓ Вопрос»**.
- Куратор отвечает **реплаем** на пересланное сообщение — бот отправляет ответ участнику с пометкой «💬 Ответ куратора». Отвечать может любой из кураторов.
- `/task` — повторить текущее задание. `/stats` (кураторам) — сколько оплатили и сколько прошли все 7 дней.
- Контент дней — `content.py` (сейчас заглушки). Видео к дню: отправь видео боту, ответь на него `/fileid`, вставь полученный id в поле `video`.

Кураторам нужно один раз нажать `/start` в боте, иначе Telegram не даст боту им писать.

## Как подтверждается оплата

Никаких ResultURL и веб-сервера. Бот сам раз в 30 секунд спрашивает у Robokassa статус неоплаченных счетов (XML-интерфейс `OpStateExt`, подпись паролем #2). Код 100 = оплачено, бот выдаёт доступ. Покупатель может нажать «Проверить оплату», чтобы не ждать. Доступ выдаётся по счёту только один раз, счета старше 2 суток не опрашиваются.

## Что видит модератор Robokassa (как у OMGbot)

| Требование | Где в боте |
|---|---|
| Описание услуги с ценой | «О челлендже и цена», `/info` → Контакты, описание бота |
| Оферта | Кнопка «Оферта» на старте и в `/info`, ссылка перед оплатой |
| Политика ПДн | Кнопка «Политика» на старте и в `/info` |
| Контакты | `/info` → Контакты, `/help` |
| Реквизиты «Самозанятый ФИО, ИНН» | `/info` → Реквизиты, описание бота |
| Получение услуги и возврат | `/info` → Оплата и возврат |

## Где живёт

Репозиторий `rooterok/pocketSMM`, отдельный проект Railway `pocket-smm` (start `python main.py`, Volume `/data`). С OMGbot не связан ничем, кроме того что продавец — тот же самозанятый.

Магазин Robokassa — `pocketMarketolog`. Настройки магазина: алгоритм хеша **MD5**, пароли #1 и #2 → `ROBOKASSA_PASSWORD1/2`; Result/Success/Fail URL бот не использует (там ссылка на бота). Робочеки СМЗ — включить.

Оферта и политика: если `OFFER_URL`/`PRIVACY_URL` пустые, кнопки «Оферта»/«Политика» и команды `/offer`, `/privacy` показывают текст из `docs/` прямо в боте.

## Запуск

1. Бот в @BotFather → `BOT_TOKEN`.
2. Кураторы нажимают `/start` в боте; их Telegram ID → `ADMIN_IDS` (через запятую).
3. Оферта и политика — в `docs/`, бот показывает их сам (или опубликуй в Telegraph и укажи `OFFER_URL`/`PRIVACY_URL`).

## Проверка оплаты

Тестовый режим Robokassa с этой схемой не работает (OpState не видит тестовые счета), поэтому проверяй одной боевой оплатой: временно `PAYMENT_AMOUNT=10.00`, оплатить, получить День 1, вернуть 5000.00.

## Команды

`/start`, `/info`, `/help`, `/stats` (только `ADMIN_IDS`).
